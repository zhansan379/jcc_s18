# 英雄标注工具

> 文档索引：[docs/README.md](../docs/README.md) · 模块摘要：[docs/modules/labeler.md](../docs/modules/labeler.md)

给截图里裁出来的 3D 棋子人工打标签，产出**带名字的裁剪图**，供以后做
「VLM few-shot 检索」或「本地模板匹配」。

双击 `英雄标注工具.exe` 即可（单文件，无需 Python 环境）。

---

## 用法

```
打开截图…   选一张或多张对局截图（默认已载入 D:\Download 下那两张样例）
上一张/下一张  在多张截图之间切换
```

界面分三块：

| 区域 | 内容 |
|---|---|
| 左侧 | 当前棋子的放大预览（3×），下面是 编号/棋盘或备战席/星级/裁剪尺寸 |
| 右侧 | S18 全部 65 个英雄的 2D 头像，点一下就完成标注 |
| 底部 | **本图全部棋子的缩略条** —— 绿框=已标注，灰框=未标注，点缩略图可跳转 |

顶栏右侧实时显示 `本图 3/12 · 累计 27 个不同棋子`。

### 快捷键

| 键 | 作用 |
|---|---|
| 空格 / Enter | 跳到下一个未标注 |
| Backspace | 清空当前格 |
| ← → | 上一个 / 下一个棋子 |
| Ctrl+F | 搜索英雄名（过滤右侧网格） |

标注完会自动跳到下一格未标注的。

## 数据落在哪

```
jcc_s18/data/hero_labels/
├── labels.json            标注记录
└── crops/<sha1>.png       裁剪原件（就是喂给 VLM 的那种图）
```

`labels.json` 结构：

```json
{
 "version": 1,
 "items": {
   "<裁剪图 sha1>": {
     "name": "瑟庄妮",
     "image": "00a5a489-....png",
     "unit": 3,
     "star": 1,
     "area": "board",
     "box": [625, 576, 696, 583],
     "crop": "crops/<sha1>.png",
     "ts": 1793602581
   }
 }
}
```

**用 sha1 做键**，所以：

- 同一张图里重复出现的同一个棋子（多个 1★ 拷贝）**标一次就全绿**
- 不同截图里出现的同一个棋子自动复用之前的标注
- `crops/<sha1>.png` 天然就是一份「游戏内模板」，可以直接当 VLM 的 few-shot 参考图

---

## 关于右侧的 65 个头像

来自 `data/heroicons_s18/`（文件名=英雄名），是**官方 2D 原画**。

注意这批图标里还包含 S18 的野怪单位（峡谷迅捷蟹、苍蓝哨戒、绯红印记树怪等），
它们在对局里也可能作为棋子出现，所以没有过滤掉。

## 重新打包

```bash
cd jcc_s18\labeler
python build.py          # 产物：labeler\英雄标注工具.exe（约 82 MB）
```

依赖：`PyQt6`、`numpy`、`scipy`、`Pillow`、`PyInstaller`。

exe 不带数据，运行时按 `exe所在目录\..\data` 找英雄图标，所以
**exe 必须留在 `jcc_s18\labeler\` 下**，不能单独拷走。

## 后续怎么用这批标注

1. **VLM few-shot**：把标注好的 `crops/*.png` 和名字拼成一张参考图，
   和新截图一起送进模型，让它「照着这些已确认的样子找」
2. **本地模板匹配**：已经证明「2D 原画 ↔ 3D 模型」跨渲染匹配不可靠，
   但「3D 模型 ↔ 3D 模型」是同一渲染来源，用
   `hero_names.desc()` 的 16×16 模糊灰度描述子 + 余弦相似度就能直接做最近邻
3. **约束校验**：标注数据攒够后，可以用羁绊面板计数反查标注质量
