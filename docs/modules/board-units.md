# board_units：棋盘单位

文件：`core/board_units.py`  
入口：`extract(img) -> units[]`

## 职责

从整图里找己方绿色血条，推断每个单位的：

- 星级（血条左侧雪佛龙颜色）
- 位置（血条左上角，归一化）
- 棋盘 / 备战席
- 身上最多 3 个装备（模板匹配）

不负责名字；名字见 [hero-names](hero-names.md)。

## 输出

```json
{
  "star": 2,
  "star_color": "银",
  "area": "board",
  "pos": [0.3835, 0.3619],
  "box": [736, 397, 829, 403],
  "items": [
    {"name": "反曲之弓", "score": 0.77,
     "box": [0.38, 0.37, 0.40, 0.40]}
  ]
}
```

- `pos`：血条左上角 / 图宽高。
- `box`：血条像素框。
- `items[].box`：装备框，归一化。
- `area`：`y/H >= 0.580` 为 `bench`，否则 `board`。

## 实现步骤

### 1. 找血条

`find_bars(a)`：

- 绿色判据：`G > 150 & G-R > 35 & B > 60`（薄荷绿；草地 B 低）。
- 横向闭运算 `1×7` 桥接分段血条。
- 逐行找宽 55~150 的绿色段，再把上下相邻、水平重叠的段合并。
- 过滤：高 4~20、至少 4 行、`y0/H <= 0.755`（排除底部经验条）。
- 血条上下必须有暗边（`<70` 占比 ≥55%）。
- 排除「等级数字 + 血量」的玩家状态条：左侧方框里有大片近白像素。

### 2. 星级

`star_of_bar()` 以血条左沿为中心，左右各取 42px、上下扩 10/8px，交给 `classify_marker()`：

- 只统计有颜色像素（`max>70 & max-min>20`）。
- 银蓝：`h 165~225, s<0.35, v>0.50`，计数 >60 → **2★ 银**。
- 金色：`h 30~62, s>0.55, v>0.80`，计数 >60 → **3★ 金**。
- 否则 **1★ 铜**。

用绝对像素数而不是平均色，因为 1★/2★ 两组完全分离。

### 3. 装备格

`find_item_boxes()`：

- 从血条下方 `y1+4` 到 `y1+h*7`，在血条左右扩展范围内找黑边方块。
- 黑边 `val<40`，宽 22~42、高 24~46，内部饱和度标准差 ≥18。
- 最多 3 个。

### 4. 装备匹配

`match_item(img, box)`：

- 裁图后内缩 2px 去黑边，统一 56×56。
- 三特征：
  - 灰度 NCC（去均值归一化）
  - HSV 直方图交集（H 18 bin + S 8 bin）
  - 3×3 分块灰度相关
- 加权：`0.42*ncc + 0.30*hist + 0.28*cells`
- 参考库：`data/equipment_s18/` 139 张，一次性堆矩阵，矩阵乘法算完。
- 阈值：`score >= 0.55` 才收。

同一个 `match_item` 也被 [item-bench](item-bench.md) 复用。

## 已知限制

- 只针对 16:9；没有 `wide` 分支。
- 战斗阶段的伤害数字/技能光效会产生绿色/金色干扰，建议在备战阶段截图。
- 血条被遮挡、重叠、或 UI 缩放变化会漏检。
- 3★ 金色与某些金色特效可能混淆；当前靠像素计数阈值。
- 只输出装备名和分数，不做「散件/成装」语义判断。
- 备战席阈值 `0.580` 是硬编码，换布局要重标。
