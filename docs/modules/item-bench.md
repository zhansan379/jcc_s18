# item_bench：最左侧装备栏

文件：`core/item_bench.py`  
入口：`extract(img, layout=None) -> items[]`

## 职责

读屏幕最左侧竖排装备栏（散件/道具），输出装备名、匹配分数、像素框。

## 输出

```json
[
  {"name": "反曲之弓", "score": 0.77, "box": [19, 108, 78, 165]}
]
```

## 栅格

`GRID` 只有 `16_9`，全部按**图片高度**换算（基准 1919×1097）：

| 参数 | 值 | 含义 |
|---|---|---|
| `x0` | 0.0182 | 左边界 / H |
| `x1` | 0.0711 | 右边界 / H |
| `y0` | 0.0985 | 首格上沿 / H |
| `pitch` | 0.0629 | 行距 / H |
| `h` | 0.0520 | 格高 / H |
| `rows` | 9 | 最多检查 9 行 |
| `min_std` | 25 | 空格饱和度标准差阈值 |
| `min_score` | 0.55 | 装备匹配阈值 |

`x0/x1/y0/pitch/h` 都乘 `H`，所以换分辨率（同比例）仍可用；但**没有 wide 布局**，`W/H > 2.0` 时 `GRID.get("wide")` 为空，直接返回 `[]`。

## 实现

1. 按栅格逐行算 `box`。
2. 内部区域（去掉 6px 边）饱和度标准差 `< 25` 判空位。
3. `board_units.match_item(img, box)`：
   - 56×56、去 2px 黑边；
   - 0.42 灰度 NCC + 0.30 HSV 直方图 + 0.28 3×3 分块；
   - 139 张 `data/equipment_s18/` 参考图。
4. `score < 0.55` 丢弃。
5. 输出按行序。

## 已知限制

- 仅 16:9；宽屏返回空列表。
- 栅格是按 1919×1097 实测折算，UI 缩放/皮肤变化会错位。
- 空位判定依赖饱和度；深色但非空的道具可能被当成空位，亮背景可能被当成有道具。
- 装备名来自参考图文件名；新增装备需要在 `data/equipment_s18/` 放图标。
- 与 `board_units` 共用匹配函数，改权重会同时影响棋子装备和装备栏。
