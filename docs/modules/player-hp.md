# player_hp：右侧玩家列表

文件：`core/player_hp.py`  
入口：`extract(img, layout=None) -> {layout, fast, players, self}`

## 职责

读右侧 8 人列表：排名、名字、血量，并标出自己。

## 输出

```json
{
  "layout": "16_9",
  "fast": true,
  "players": [
    {"rank": 1, "name": "小小木头", "hp": 95, "is_self": false},
    {"rank": 8, "name": "（我）", "hp": 80, "is_self": true}
  ],
  "self": {"rank": 8, "name": "（我）", "hp": 80, "is_self": true}
}
```

`scan.py` 只取 `players` 和 `self.hp`，写到 `玩家排名` / `我的血量`。

## 布局

| layout | 触发 | 区域 | 说明 |
|---|---|---|---|
| `16_9` | `W/H <= 2.0` | `box=(0.820,0.030,1.000,0.800)` | 1919×1097 模拟器 |
| `wide` | `W/H > 2.0` | `box=(0.880,0.010,0.985,0.960)` | 2712×1220 宽窗口 |

`pick_layout()` 只看宽高比，不判断客户端；两种都是金铲铲。

## 快速路径

1. 在右侧竖带里找**橙色头像环**：
   `R>150 & max-min>70 & R>G & G>=B`，在 `av_x` 范围内按行计数。
2. 连续 ≥3 像素、高度 25~95 的带作为一行；用中位间距补顶部缺失的一行。
3. 每行分两块 OCR（`use_det=False`）：
   - 名字：`name_dy` / `name_x`
   - 血量：`num_dy` / `num_x`
4. 血量解析 `_digits()` 容忍 `X100`、`%95`、`x84`、`80C`、`815`：
   - 结尾取 1~3 位数字；
   - 3 位且 >100 时取前两位（`815 → 81`）；
   - 只接受 0~100。
5. 名字必须含中文，否则置 `None`。

## 慢速回退

头像环找不到（换皮肤/改版）或有效行 <4 时：

- 整条竖带放大后跑完整 OCR（带 det，`box_thresh=0.2, thresh=0.2`）。
- 按 y 排序；每个血量数字向上 90px 内找最近的中文名字。
- 这条路径约 2~3.4s。

## 排名与「自己」

- 按 y 排序后，血量必须**单调不增**；一旦上升就截断（防止读到非列表文字）。
- 最多 8 行。
- `self_rule="no_name"`：第一行没有中文名字的视为自己，名字改成 `（我）`。
- 金铲铲手游里自己那行通常只有数字、没有名字，头像更大、环是金色。

## 已知限制

- 头像环颜色/皮肤变化会触发慢速回退。
- 顶部行可能与 UI 粘连，`_row_bands` 会丢弃异常高的带。
- 名字 OCR 可能带标点/漏字；不做名单校验。
- 血量 >100 或格式异常会被丢弃，导致行数不足。
- 只支持 8 人列表；其他模式未验证。
