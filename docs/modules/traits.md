# traits：左侧羁绊面板

文件：`core/traits.py`  
入口：`extract(img, layout=None, max_rows=7) -> traits[]`

## 职责

读左侧羁绊面板的每一行：名称、当前数量、档位串、当前激活档位。

## 输出

```json
[
  {"name": "永恒之森", "count": 3, "tiers": "2/3/4", "active": 3},
  {"name": "主宰", "count": 2, "tiers": "1/2", "active": 2}
]
```

- `count`：面板上的当前计数。
- `tiers`：档位阈值串，如 `2/3`、`2/4/6`。
- `active`：`tiers` 中 ≤ `count` 的最大值；没有则为 `null`。

## 布局

| layout | 触发 | 面板框 | 行起点/行距 |
|---|---|---|---|
| `16_9` | `W/H <= 2.0` | `(0.050,0.075,0.190,0.580)` | `y0=28`, `pitch=72.8` |
| `wide` | `W/H > 2.0` | `(0.030,0.050,0.190,0.680)` | `y0=80`, `pitch=102.8` |

两种布局的排版不同：

- `16:9`：名字一行，下一行是「当前 / 下一档」（如 `2/3`），`tiers=None`，从同一块文本里拆数字。
- `wide`：名字一行；下一行左侧数量、右侧完整档位串（如 `2 / 2/4/6`），`tiers` 单独一块。

## 实现

1. 按 `box` 裁面板。
2. 最多 7 行，按 `y0 + k*pitch` 定位。
3. 名字块 OCR：
   - 去掉空白；
   - 必须含中文，否则停止（面板到底或布局变了）。
4. 数量/档位块 OCR：
   - `_norm()` 修常见 OCR 数字误读：`T/一/I/l→1`、`O/o→0`、`S→5`、`B→8`、`Z→2`、`g/q→9`。
   - `16:9`：从整行数字里取 `parts[0]` 为 count，其余为 tiers。
   - `wide`：count 取 `num` 第一个 1~2 位数字；tiers 取 `tiers` 块的数字串，用 `/` 连接。
5. `active` 计算。

## 已知限制

- 面板行数超过 7 会截断。
- 换 UI 版本、语言、UI 缩放会错位；必须重标 `LAYOUTS`。
- `16:9` 下 count/tiers 挤在同一块，格式变化时可能错位；README 的「面板字段错位」指的就是这类情况。
- 只做数字正则，不校验羁绊名是否属于 S18 名单。
- 空面板/未开局时可能只读到 0~2 行；`scan.py` 在少于 3 条时写 `_告警`。
